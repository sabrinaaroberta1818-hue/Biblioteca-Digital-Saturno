# Biblioteca-Digital-Saturno

A Biblioteca Digital Saturno é uma aplicação web desenvolvida para o gerenciamento de uma biblioteca pessoal. A plataforma permite que o usuário organize seu acervo digital, cadastre livros, gerencie categorias, marque favoritos e mantenha uma lista de leitura.

O sistema foi desenvolvido com HTML, CSS e JavaScript no Front-end, Python (Flask) no Back-end e SQLite como banco de dados, buscando oferecer uma experiência simples, intuitiva e funcional para o gerenciamento de livros digitais.
