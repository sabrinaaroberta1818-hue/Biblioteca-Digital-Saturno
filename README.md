# Saturno — Biblioteca Digital

Front-end demonstrativo de uma biblioteca digital, desenvolvido com HTML, CSS e JavaScript puro.

## Funcionalidades implementadas
- Dashboard com indicadores, disponibilidade, gráfico ilustrativo, empréstimos recentes e atividades.
- Catálogo com busca por título/autor e filtros por categoria e ano.
- Favoritos e lista "Quero ler".
- Cadastro, edição e exclusão de livros.
- Cadastro e exclusão de categorias (não permite excluir categoria que ainda tenha livros associados).
- Cadastro e bloqueio/desbloqueio de usuários.
- Registro de empréstimos e devolução de livros.
- Filtros de empréstimos.
- Alternância entre modo Administrador e Leitor.
- Tema claro/escuro.
- Persistência local usando `localStorage`.
